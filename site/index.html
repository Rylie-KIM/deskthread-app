Install

Three steps.

Needs macOS on Apple silicon, Homebrew and about 10 GB of disk.

# 1. get the code and the tools
git clone https://github.com/Rylie-KIM/deskthread-app.git
cd deskthread-app
brew install ollama uv
make setup ui

# 2. download the model once (about 7 GB)
OLLAMA_HOST=127.0.0.1:11435 OLLAMA_NO_CLOUD=1 ollama serve &
OLLAMA_HOST=127.0.0.1:11435 ollama pull gemma4:e4b
kill %1

# 3. build the invented demo laptop (143 files) and start
make demo-data
make run
