Local-first assistant for managers

You already wrote it down. It never leaves your laptop.

DeskThread joins notes, mail, reminders and screenshots written weeks apart in different words, quotes exactly where each point came from, and says "not found" when the answer is not there.

Download for Mac ↓ How to install

Prototype. Runs on macOS with Apple silicon, in your browser at a local address. Windows is not tested. All sample data is invented.

The one rule

Your knowledge stays yours.

Nothing leaves

The app can only connect to the model on 127.0.0.1. A test fails if any other code tries.

No copies

No database, no index, no log file. The app writes nothing to disk.

You choose

Every source starts Off. One click allows, one click stops, at once. Private apps stay locked.

Honest answers

The model points at a note and a line; code copies the quote. No support means "not found".

The moment it is built for

A one-to-one tomorrow. Six weeks of scattered notes.

Searching "development goals" finds nothing, because the notes say course, conference, intro and ownership. DeskThread joins them and shows its sources.

Install

Three steps. Then it works offline.

Needs macOS on Apple silicon, Homebrew, Node.js, and about 10 GB of free disk for the model.

# 1. get the code and the tools
git clone https://github.com/Rylie-KIM/deskthread-app.git
cd deskthread-app
brew install ollama uv
make setup ui

# 2. download the model once (about 9 GB)
OLLAMA_HOST=127.0.0.1:11435 OLLAMA_NO_CLOUD=1 ollama serve &
OLLAMA_HOST=127.0.0.1:11435 ollama pull gemma4:e4b
kill %1

# 3. build the invented demo laptop and start
make demo-data
make run
  1. Get the code and the toolsThe model server (not the desktop app), a Python installer, and the page. Dependencies are pinned with hashes; no install script runs.
  2. Download the model onceThe only large download. After it, nothing needs the network.
  3. Start itYour browser opens a local address. Choose the demo-laptop folder, press Work profile, then Prepare.
