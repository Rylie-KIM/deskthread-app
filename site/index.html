DeskThread

Find what you wrote down. Your notes never leave your laptop.

A local-first assistant for managers. It joins notes, mail, reminders and screenshots written weeks apart in different words, quotes exactly where each point came from, and says "not found" when the answer is not there.

Runs on your machine · no account · no telemetry

Download source (.zip) View on GitHub

Prototype, work in progress: the reading, access and answer parts are built and tested and run from the terminal. The browser interface is not built yet. macOS on Apple silicon only; Windows is not tested.

What it promises

Nothing leaves

The only connection the app can open is to the model server on 127.0.0.1. A test fails if any other code tries.

No copies

No database, no index, no log file. The app writes nothing to disk.

You choose what it sees

Every source starts Off. One click grants, one click revokes, with immediate effect. Private apps stay locked off.

Honest answers

The model points at a note and a line; code copies the quote. No support means "not found".

Install

git clone https://github.com/Rylie-KIM/deskthread-app.git && cd deskthread-app
brew install ollama uv
make setup

# download the model once (about 9 GB); after this it works offline
OLLAMA_HOST=127.0.0.1:11435 OLLAMA_NO_CLOUD=1 ollama serve &
OLLAMA_HOST=127.0.0.1:11435 ollama pull gemma4:e4b
kill %1

Check what you downloaded

  • The source is public: read it before you run it. Dependencies are pinned with hashes in uv.lock.
  • The model is pinned by digest and refused if it differs:
    eb2177adf7646d15faead94fdad6d3e170dc8015653418a3b7d5d52a6380be5b (gemma4:e4b, Apache-2.0).
  • Run make check: lint, type check and 100 tests, no model needed.
