Local-first assistant for managers

You already wrote it down. It never leaves your laptop.

DeskThread joins notes, mail, reminders and screenshots written weeks apart in different words, quotes exactly where each point came from, and says "not found" when the answer is not there.

Download for Mac ↓ How to install

Prototype in progress. It runs in the terminal today; the browser interface is not built yet. macOS on Apple silicon. Windows is not tested.

One rule: your knowledge stays yours.

Nothing leaves

The only connection the app can open is to the model on 127.0.0.1. A test fails if any other code tries.

No copies

No database, no index, no log file. The app writes nothing to disk.

You choose

Every source starts Off. One click grants, one click revokes, at once. Private apps stay locked.

Honest answers

The model points at a note and a line; code copies the quote. No support means "not found".

The moment it is built for

A one-to-one tomorrow. Six weeks of scattered notes.

Install

Three steps. After the model is downloaded, it works offline.

Needs macOS on Apple silicon, Homebrew, and about 10 GB of free disk for the model.

# 1. get the code and the tools
git clone https://github.com/Rylie-KIM/deskthread-app.git
cd deskthread-app
brew install ollama uv
make setup

# 2. download the model once (about 9 GB)
OLLAMA_HOST=127.0.0.1:11435 OLLAMA_NO_CLOUD=1 ollama serve &
OLLAMA_HOST=127.0.0.1:11435 ollama pull gemma4:e4b
kill %1

# 3. try it on the invented demo laptop
uv run python demo-data/make_demo_data.py
uv run python -m scripts.ask
  1. Get the code and the toolsThe model server (not the desktop app) and a Python installer. Dependencies are pinned with hashes.
  2. Download the model onceThe only large download. After it, nothing needs the network.
  3. Run itIt prepares tomorrow's one-to-one from sample notes, then takes your questions. An empty line ends the session and stops the model.
