A native Mac app for the notes you already have

You already wrote it down. It never leaves your laptop.

DeskThread finds what you wrote down in Notes, Calendar, Mail, Reminders and your folders, quotes exactly where each point came from, and says "not found" when the answer is not there. It runs entirely on your Mac.

Download for Mac ↓ How to install

Prototype. A native Mac app for Apple silicon, in its own window: not a website, no browser, no history kept. Windows is not tested. All sample data is invented.

The one rule

Your knowledge stays yours.

Nothing leaves

The AI runs on this Mac. The app can only connect to 127.0.0.1, and a test fails the build if any other code may open a connection. Turn Wi-Fi off: it still answers.

No copies

No database, index or cache. The app writes nothing to disk, counts every write (zero), and keeps what it reads in memory until you clear it.

You choose

Everything starts Off and nothing is ticked for you. A switch allows reading, the same switch stops it. Read is the only permission that exists.

Honest answers

The AI names a note and a line; code copies the quote. A real quote about something else is dropped, notes that give orders are ignored, and no support means "not found".

The app

Every part shows what it is doing.

Access

Choose what it may read: Calendar, Mail, Notes, Reminders and folders. Everything starts Off. A period for Calendar and Mail. File types it cannot read are listed as not supported, not skipped silently.

Ask

Ask in your own words, or press Prepare on the next meeting. Every point has its exact quote, date and source, and one click opens the original. Possibly related notes are kept apart. Stop ends a question at once.

My data

Check it now lists the app's own connections as macOS prints them, with the command to run yourself. Folders are compared with how they were when chosen. A log keeps what was allowed and read.

AI model

Eight models, all run on this Mac, with parameters and download size. Gemma 4 is the default and is pinned. A small search helper finds notes by meaning; it is not a chat AI.

Pictures

The text in screenshots is read by macOS's own text recognition, in memory, when you switch Pictures on. The AI only looks at pictures that hold no text.

End session

Removes what was read and your settings, stops every program, and gives a receipt that says how each number is counted and how you can check it without the app.

The moment it is built for

A one-to-one tomorrow. Six weeks of scattered notes.

A plain search for the words you would use finds nothing, because the notes say course, conference, intro and ownership. DeskThread joins them and shows its sources.

Install

Three steps. Then it works offline.

Needs macOS on Apple silicon, Homebrew, Node.js, and about 10 GB of free disk for the model. It is a Mac app, not a website: it runs entirely on your Mac.

# 1. get the code and the tools
git clone https://github.com/Rylie-KIM/deskthread-app.git
cd deskthread-app
brew install ollama uv
make setup ui

# 2. download the model once (about 7 GB)
OLLAMA_HOST=127.0.0.1:11435 OLLAMA_NO_CLOUD=1 ollama serve &
OLLAMA_HOST=127.0.0.1:11435 ollama pull gemma4:e4b
kill %1

# 3. build the invented demo laptop (143 files) and start
make demo-data
make run
  1. Get the code and the toolsThe model server (not the desktop app), a Python installer, and the page. Dependencies are pinned with hashes; no install script runs.
  2. Download the model onceThe only large download. After it, nothing needs the network.
  3. Start itDeskThread opens in its own Mac window. Click "Try it with the demo laptop", then Prepare. Optional: in the AI model tab, download the search helper (0.6 GB).

Check it yourself

Do not take this page's word for it.

Check it now

In the app, My data, Check it now runs macOS's own connection listing for the app's programs and shows the command to run in Terminal yourself. Every line should say 127.0.0.1.

Turn Wi-Fi off

It still answers. The only time anything uses the internet is a model download that you start yourself.

A receipt

End session ends with a receipt: items read per source, files saved by the app (zero), whether anything went outside, and which of your folders changed.

Read the source

Everything is public on GitHub. Run make check: lint, type checks and the tests, no model needed.

One pinned model

The default is gemma4:e4b, Apache-2.0; a different digest is refused. Seven more can be chosen; only the first three were run with DeskThread.

This page is quiet too

No analytics, no cookies, no fonts or scripts from other sites. The download is served by GitHub.

What it does not promise: that memory is physically erased (that belongs to the operating system), that the connection list catches a very short connection, or anything about other apps on your Mac, such as Calendar syncing with iCloud. Mac only; Windows is not tested.
